# Task 6: Host a Static Website with GitHub Pages

## Objective

Deploy a simple static website using GitHub Pages and make it publicly accessible for free.

## Tools Used

- GitHub
- GitHub Pages
- HTML5
- CSS3

## Project Description

This project demonstrates how to create and deploy a static website using HTML and CSS. The website includes a welcome section, an About Me section, and basic styling for a clean, responsive design.

GitHub Pages is used to host the website directly from a GitHub repository.

## Features

- Simple and responsive website layout
- HTML structure and CSS styling
- Navigation link to GitHub
- Free hosting using GitHub Pages
- Publicly accessible website

## Project Structure

```text
my-first-website/
├── index.html
└── README.md
```

## Steps to Deploy

1. Created a new public repository on GitHub named `my-first-website`.
2. Created an `index.html` file containing the website code.
3. Added CSS styling to customize the appearance.
4. Committed the files to the `main` branch.
5. Opened the repository's **Settings → Pages**.
6. Selected **Deploy from a branch**.
7. Selected the `main` branch and the `/(root)` folder.
8. Saved the settings and waited for GitHub Pages to publish the website.
9. Opened the published website URL to verify the deployment.
